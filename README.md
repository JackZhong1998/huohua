# 火花

AI 原生互动视频平台的 Web 演示应用。

## 本地运行

```bash
npm install
npm run dev
```

## GitHub Pages

推送到 `main` 后，GitHub Actions 会构建静态站点并自动发布。

- 产品演示：`https://jackzhong1998.github.io/huahuo/`
- 商业计划书网页：`https://jackzhong1998.github.io/huahuo/bp/`

仓库不保存商业计划书 Markdown 原稿、环境变量或 Sites 发布配置；商业计划书仅作为产品中的网页组件发布。
